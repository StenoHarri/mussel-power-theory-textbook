Short vowels can be 

spelling based (WACH -> watch)


Or phonetic (WOCH -> watch)

(if you're American, then WAUCH -> watch, but that won't be in the dictionary, so try sticking to spelling)

Sticking to spelling is a good idea anyway, as you're less likely to run into conflicts, like bury/berry

But phonetics is a nice fallback for weird spellings
FREND -> friend
